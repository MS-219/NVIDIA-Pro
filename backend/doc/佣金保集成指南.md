# 佣金保灵活用工平台集成指南

## 1. 概述

本文档说明如何将佣金保灵活用工平台集成到 Orin Platform 项目中，实现自动化的提现付款功能。

## 3. 配置步骤

### 3.1 初始化数据库

```bash
cp .env.example .env
./deploy-docker.sh up
```

首次创建 MySQL 数据卷时会自动执行 `deploy/mysql-init`。现有生产库升级必须使用单独审核过的迁移，不要重复执行初始化基线。

### 3.2 配置环境变量

从商户门户获取以下信息并写入服务器 `.env`，不要提交到仓库：

```dotenv
ORIN_BOSSKG_ENABLED=true
ORIN_BOSSKG_MER_ID=YOUR_MER_ID
ORIN_BOSSKG_PROVIDER_ID=YOUR_PROVIDER_ID
ORIN_BOSSKG_TASK_ID=YOUR_TASK_ID
ORIN_BOSSKG_DES_KEY=YOUR_DES_KEY
ORIN_BOSSKG_PRIVATE_KEY=YOUR_PRIVATE_KEY
ORIN_BOSSKG_PUBLIC_KEY=YOUR_PUBLIC_KEY
ORIN_BOSSKG_CONTRACT_NOTIFY_URL=https://your-domain.com/api/bosskg/notify/contract
ORIN_BOSSKG_PAYMENT_NOTIFY_URL=https://your-domain.com/api/bosskg/notify/payment
```

### 3.3 配置IP白名单

在佣金保商户门户 -> 企业管理 -> 接口设置 中，添加服务器IP到白名单。

### 3.4 生成RSA密钥对

如果没有密钥对，可以使用以下命令生成：

```bash
# 生成私钥
openssl genrsa -out merchant_private.pem 1024

# 从私钥生成公钥
openssl rsa -in merchant_private.pem -pubout -out merchant_public.pem

# 转换为PKCS8格式（Java需要）
openssl pkcs8 -topk8 -inform PEM -in merchant_private.pem -outform PEM -nocrypt -out merchant_private_pkcs8.pem
```

将 `merchant_private_pkcs8.pem` 的内容（去掉头尾标识）填入 `merchant-private-key`。
将 `merchant_public.pem` 上传到佣金保商户门户。

## 4. 业务流程

### 4.1 签约流程 (小程序/H5)

#### 流程 A：H5 人脸识别签约 (推荐)
1. 用户在小程序填写身份信息（姓名、身份证、手机号、收款账号）
2. 调用 `/api/bosskg/contract/signing-url` 接口获取 H5 签约链接
3. 小程序跳转至 web-view 页面打开该链接
4. 用户在 H5 页面完成人脸识别和协议签署
5. 佣金保异步通知签约结果，或用户返回小程序后手动刷新状态

#### 流程 B：静默/无感签约 (API)
1. 用户在小程序填写完整信息并上传身份证正反面照片
2. 调用 `/api/bosskg/contract/sign` 接口发起签约
3. 佣金保审核通过后回调通知结果

### 4.2 付款流程

1. 用户申请提现，创建提现记录
2. 管理员在后台审核并点击"佣金保付款"按钮
3. 调用 `/api/admin/bosskg/pay/{id}` 接口
4. 系统向佣金保发起付款请求
5. 佣金保付款成功/失败后回调 `/api/bosskg/notify/payment`
6. 提现状态自动更新

### 4.3 状态同步

如果回调未收到，可以手动同步状态：
- 单条同步：`POST /api/admin/bosskg/sync/{id}`
- 批量同步：`POST /api/admin/bosskg/sync-pending`

## 5. API 接口说明

### 5.1 用户端接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/bosskg/contract/enabled` | GET | 检查佣金保是否启用 |
| `/api/bosskg/contract/status` | GET | 获取用户签约状态 |
| `/api/bosskg/contract/signing-url` | POST | 获取H5签约链接 (人脸识别) |
| `/api/bosskg/contract/sign` | POST | 发起API签约 (需传照片) |
| `/api/bosskg/contract/refresh` | POST | 刷新签约状态 |

### 5.2 管理后台接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/admin/bosskg/status` | GET | 获取佣金保状态和余额 |
| `/api/admin/bosskg/pay/{id}` | POST | 发起佣金保付款 |
| `/api/admin/bosskg/sync/{id}` | POST | 同步单条订单状态 |
| `/api/admin/bosskg/sync-pending` | POST | 批量同步付款中订单 |

### 5.3 回调接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/bosskg/notify/contract` | POST | 签约结果回调 |
| `/api/bosskg/notify/payment` | POST | 付款结果回调 |

## 7. 注意事项

### 7.1 付款限制

- 单笔金额：10元 ~ 9.8万元
- 每人每月：不超过9.8万元
- 银行卡/支付宝：无每日笔数限制

### 7.2 备注敏感词

以下词汇不能出现在备注中：
- 工资、薪酬、提现、薪、补贴
- 分红、奖金、返现、劳务费
- 分润、备用金、咨询

推荐使用"服务费"作为备注，可免审核。

### 7.3 签约要求

- 用户年龄限制：18-65岁
- 公司董监高不可签约
- 签约通常1-3分钟终态

### 7.4 回调处理

- 必须返回 `SUCCESS`（大写）
- 通知间隔：2分钟一次，共5次重试
- 建议实现状态同步接口作为备份

## 8. 常见问题

### Q1: 数据解密失败
检查 DES 密钥是否正确配置。

### Q2: 签名异常
检查商户私钥格式，确保使用 PKCS8 格式且去掉头尾标识。

### Q3: 验签异常
检查平台公钥是否正确下载。

### Q4: 商户不存在该任务
检查任务ID是否为"进行中"状态的任务。

### Q5: 商户余额不足
请在佣金保商户门户充值。
